After the download

  1. Open the downloaded file, Nexy-Setup.
  2. If Windows shows "Windows protected your PC", choose More info, then Run anyway.
  3. Install Nexy. When it starts, it sets everything up and talks you through the rest.

You need a ChatGPT account. Nexy works on Windows 11.
